Notation :
CRLF : \r\n
URI : /index.html (example)

Moethods :


It is RECOMMENDED that all HTTP senders and recipients support,
at a minimum, request-line lengths of 8000 octets.

Request example :
GET /index.html HTTP/1.1
Host: localhost
Accept: text/html
Accept-Language: en-US, en; q=0.5

Decomposed request example :
request-line	=	method request-target HTTP-version   CRLF
>>> 				GET    /index.html    HTTP/1.1       CRLF

origin-form    = absolute-path [ "?" query ] : request-target
>>> http://localhost/index.html?q=an_id_for_example

If URI too long : return 414
If whitespace in request-target : return 400
If URI empty : return origin-form = /
